# Лог генерації вимог та Use Cases

## Prompt 1
**Запит до AI:** Згенеруй EARS-вимоги, Gherkin-сценарії та Use Case діаграму (Mermaid) для електронного журналу. Актори: Викладач, Студент, Email-сервіс.
**Відповідь AI (дослівно):**
"Ось базова структура для електронного журналу.
EARS-вимоги:
- WHEN the Teacher wants to add a grade, the system SHALL save it quickly.
Діаграма Mermaid:
\`\`\`mermaid
flowchart LR
    Teacher --|> User
    Student --|> User
    Email-Service --> SendEmail
\`\`\`"

## Prompt 2
**Запит до AI:** Виправ діаграму. У Mermaid flowchart для узагальнення `--|>` не працює, використай `Teacher -- "generalization" --> User`. Email-сервіс не є актором, прибери його.
**Відповідь AI (дослівно):**
"Вибачте за помилку в синтаксисі. Я виправив Mermaid-діаграму, замінивши стрілки на `generalization`, та прибрав Email-сервіс із переліку акторів. Системні кроки також видалено."

## Prompt 3
**Запит до AI:** Вимоги занадто абстрактні, а Gherkin-сценарій лише один. Напиши 3 детальні Gherkin-сценарії для UC "Виставити оцінку" (успіх, за межами діапазону, повторне виставлення). Додай блок NFR з точними числами (1000 користувачів, час < 1.5с).
**Відповідь AI (дослівно):**
"Зрозумів. Додаю три окремі Gherkin-сценарії для обробки різних результатів виставлення оцінки. Також згенеровано окремий блок NFR із вказаними числовими метриками продуктивності та навантаження."
