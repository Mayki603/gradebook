# Домен: Електронний журнал оцінювання (Electronic Gradebook)

Цей проєкт описує концептуальну доменну модель даних для електронного журналу оцінювання навчального закладу. 
Система дозволяє:
- Вести облік студентів, академічних груп та викладачів.
- Призначати викладачів на навчальні предмети (курси).
- Планувати конкретні заняття (уроки) для груп.
- Виставляти студентам оцінки за конкретні заняття із зазначенням типу оцінки та коментаря.
